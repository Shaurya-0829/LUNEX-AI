
# LUNEXIS - Next Gen Quantum Cognitive Architecture

LUNEXIS is an advanced, fully-autonomous desktop assistant built with a beautiful "liquid glass" React UI and a powerful Node.js backend. It features deep system-level control, real-time voice recognition, Groq LLM integration, and a highly aesthetic cyberpunk interface.

## 🚀 Features
- **Voice Engine**: Real-time microphone listening and text-to-speech interaction.
- **Cyberpunk UI**: Liquid glass design, 4K startup videos, and interactive plasma orbs.
- **System Automation**: Full integration with Windows to manage files, create folders, and open installed software/websites automatically.
- **Quantum Cognitive Matrix**: Driven by Llama-3 (via Groq) for instant, sub-second natural language processing.
- **Strict Master Protocols**: Personalized strictly for Shauryaa.

## 🛠️ Tech Stack
- **Frontend**: React.js, vanilla CSS, Web Speech API.
- **Backend**: Node.js, Express, SystemInformation, Node Child Processes.
